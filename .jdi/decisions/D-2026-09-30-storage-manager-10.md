D-2026-09-30-storage-manager-10 (2026-09-30): Associating a screen file with an original on the PC: the user picks files or a folder; candidates have exactly the same size in bytes and the same kind, ranked by name similarity and, when the probe reads them, duration and resolution (480x1920 on the 8.8"); the user confirms each pair, and the original's bytes are then copied into the store, which gives the file a thumbnail and makes it movable. Thumbnails come only from a local copy, are made in the background and kept in the store: images scaled to fit 160 px, videos a frame at 1 s through ffmpeg (a generic icon without ffmpeg). A file without a copy shows a generic icon for its kind and "Play on the screen" (PLAY_VIDEO or PLAY_IMAGE, then Stop) as its preview. Decided in auto mode (/jdi-discuss): the screens cannot send a file back, so the local copy is the only source of a picture.
