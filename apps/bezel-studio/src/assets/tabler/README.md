# Tabler Icons

Offline SVG catalog from the official npm package `@tabler/icons` 3.48.0.
Source: https://github.com/tabler/tabler-icons
The package archive was checked against the npm registry's SHA-512 integrity value.

`icons.js` contains all 6,220 original SVGs (outline and filled) and the
package version. Studio changes `currentColor` and outline width when an
icon is added. The backend embeds the included MIT license in each selected
SVG, so attribution travels with exported themes.
