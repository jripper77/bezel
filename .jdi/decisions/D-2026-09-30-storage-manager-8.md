D-2026-09-30-storage-manager-8 (2026-09-30): Restore re-sends a chosen set of cataloged files that have local copies to one medium (after a format on the PC or onto a new card); the default selection is that medium's entries marked missing or on another card. Before any byte is sent the total size must fit the medium's free space (else refused, saying by how much; nothing is deleted to make room) and every file must pass the preflight with the 25 MiB rev C cap. A file already there with the same name and size is skipped as present; the same name with another size is a conflict, skipped unless its overwrite is confirmed. Files go in catalog order (oldest sent first), one at a time, each verified by size; Cancel and failures behave as in moving (D-7). Restore never deletes anything. Decided in auto mode (/jdi-discuss): an upfront space check avoids a half-restored card.
