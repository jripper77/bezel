# Material Design Icons hardware subset

375 icons from the official `@mdi/svg` 7.4.47 package, downloaded from
https://registry.npmjs.org/@mdi/svg/-/svg-7.4.47.tgz.

Selected by hardware-related name tokens (pump, radiator, fan, coolant,
lightning, flash, electric, chip, memory, harddisk, server, ethernet,
network, lan, usb, power, battery, thermometer, pipe, valve, hydraulic,
gauge, speedometer, led, snowflake, heat, water), excluding brand/logo tags.
The prefixed IDs keep them distinct from the existing Tabler collection.

SVGs retain their path geometry. Root fill uses currentColor for editing;
a presentation class is added and title nodes are removed. Saved assets
receive their own Apache license and modification notice in SVG metadata.
See LICENSE and NOTICE for attribution, source and the package checksum.
