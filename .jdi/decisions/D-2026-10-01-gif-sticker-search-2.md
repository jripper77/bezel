D-2026-10-01-gif-sticker-search-2 (2026-10-01): GIFs and stickers come from KLIPY with the user's own key, behind a vendor-neutral driven port `GifSource` in bezel-core (a page of GIFs or stickers for a text, trending when it is empty; the bytes of one rendition read up to a limit); the core never names KLIPY nor an HTTP crate. The adapter is a new crate `crates/bezel-klipy` (`KlipyClient`) on `ureq` 3 with `default-features = false, features = ["rustls"]` (rustls + ring + webpki-roots; blocking, like the studio commands' `blocking` threads). The desktop builds compile no HTTP client today: tauri 2.12 depends on `reqwest` only for Android/iOS, so it sits in Cargo.lock unbuilt and without TLS. `ureq` is the phase's one new dependency (with its TLS crates; the customer id uses `getrandom` 0.3, already locked) and only bezel-studio depends on bezel-klipy, so the CLI stays without network. Requests: `GET https://api.klipy.com/api/v1/{key}/{gifs|stickers}/{search|trending}` with `q`, `page`, `per_page=24`, `customer_id` (128 random bits made once per saved key, never personal data), `locale` (`BR` in pt-BR, omitted in en), `content_filter` (`off` with "Show explicit results" on; `medium`, G and PG, otherwise: safe on a desk screen without hiding everyday reaction GIFs, which `high` drops) and `format_filter=gif,jpg`. The JSON (`result`, `data.data[]` with `id`, `slug`, `title`, `file.{hd,md,sm,xs}.{gif,jpg}.{url,width,height,size}`, and `data.has_next`) is read tolerantly: unknown fields ignored, missing renditions skipped, an item without a GIF dropped. API calls never follow a redirect (the key is in the path); files come only over HTTPS from KLIPY's file host (`static.klipy.com`), never with the key, read with a byte limit (2 MiB for a preview, 25 MiB for an item); 10 s timeout. HTTP 429 is `klipyRateLimited`, 401/403 `klipyKeyRejected`, anything else `klipyUnavailable`; no error text, log line or `Debug` output carries the key. Zero cost: no ads, no paid plan, no project key; the Share Trigger and Report endpoints are not used. Decided in auto mode (/jdi-issue).
